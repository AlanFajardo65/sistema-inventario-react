# Sistema de inventario web

Prototipo académico creado con React y Vite.

## Funcionalidades incluidas
- Consultar una lista de productos de ejemplo.
- Agregar, editar y eliminar productos.
- Buscar por nombre o categoría.
- Ver el total de productos, unidades y valor estimado del inventario.
- Identificar existencias bajas (5 unidades o menos).
- Diseño adaptable a pantallas pequeñas.

## Requisitos
- Node.js instalado.
- Terminal o consola.

## Cómo ejecutar
1. Descomprime la carpeta.
2. Abre una terminal dentro de la carpeta `sistema_inventario_react`.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre en el navegador la dirección local que indique Vite (normalmente `http://localhost:5173`).

## Limitación actual
Los datos de ejemplo están en memoria y se reinician al recargar la página. Todavía no hay una base de datos ni inicio de sesión. No describir esas funciones como terminadas.
